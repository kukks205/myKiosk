# myKiosk

Mockup ระบบส่งตรวจอัตโนมัติด้วยตนเองของผู้ป่วยสำหรับโรงพยาบาล พัฒนาด้วย SvelteKit และ Vite

## การทำงานที่ออกแบบไว้

- เสียบบัตรประชาชนเพื่ออ่านค่า CID แล้วค้นหา HN ในฐานข้อมูล
- สแกนใบนัดเพื่ออ่าน HN โดยตรง
- แสดงข้อมูลผู้ป่วยหลังค้นหาสำเร็จ
- เลือกแผนกที่ต้องการรับบริการ
- ยืนยันและส่งตรวจ พร้อมแสดงเลขคิวจำลอง

## วิธีรัน

```bash
npm install
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดงใน terminal
